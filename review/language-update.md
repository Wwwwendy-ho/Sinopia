# Device-language update

Built-in English, Simplified Chinese, Traditional Chinese, Spanish and French. Device language preferences choose the interface; unsupported preferences use English. Help includes a remembered language override. Sinopia, shortcut keys, user artwork and storage identities remain unchanged. Translation is bundled and sends no text to an external service.

Buttons, accessible labels, tooltips, help, camera guidance, alignment coach, status messages and removal confirmations use the locale catalog. Unknown messages fall back to their English source. The help copy is shorter in every language. The application script URL is versioned to refresh cached code.

Pre-publication validation: 252 combinations (six locales including unsupported German × seven viewports × three layouts × empty/loaded) passed without horizontal overflow or JavaScript exceptions. Chinese script variants and Spanish/French regional tags were checked. Physical-device proofreading remains useful for translation nuance.
